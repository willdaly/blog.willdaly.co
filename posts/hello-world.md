# Hello World

Welcome to my engineering blog. I'm Will Daly — a software engineer who writes about building systems, shipping products, and the craft of programming.

## Why a blog?

Writing forces clarity. Debugging a tricky race condition is one thing; explaining it to someone else is another. The process of putting thoughts into sentences reveals gaps in understanding that code alone never will.

## What to expect

Posts here will cover:

- **Systems design** — distributed systems, databases, architecture decisions
- **Day-to-day engineering** — tooling, workflows, lessons from the trenches
- **Deep dives** — picking apart interesting libraries, protocols, or algorithms

I'll aim for quality over quantity. Each post should be something worth bookmarking.

## Tech stack

This blog itself is a [Next.js](https://nextjs.org/) static site using the App Router, styled with [Tailwind CSS](https://tailwindcss.com/), and deployed to the edge. Posts are plain Markdown files — no CMS, no database, just files in a Git repository.

Thanks for reading.
